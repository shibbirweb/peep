# Peep desktop app

Tauri app for macOS, Windows and Linux. It shows the Peep viewer in a native window and runs the PHP viewer server (`peep-server.phar` with a bundled PHP 8.5) as a sidecar, so no PHP install is needed.

Built in Phase 8 of the [roadmap](../docs/plan/roadmap.md). Design: [implementation plan, section 12](../docs/plan/implementation.md#12-desktop-app-phase-8).
